# Contributing

This project is intentionally small. Contributions are most useful when they
preserve the core idea: numerical/procedural state is computed in Python, while
DCC-specific finishing remains downstream.

Useful contributions include:

- host compatibility reports for After Effects, Resolve/Fusion, Blender, and web glTF viewers;
- additional transform channels (rotation, scale);
- camera and light export;
- GLB support;
- USD material improvements;
- morph/deformation experiments;
- adapters for Manim, SciPy simulations, VTK/PyVista datasets, or other Python sources.

Please include a minimal reproducible example with bug reports.
